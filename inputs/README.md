# Generated input files

`siesta/` contains FDF files generated by ASE during the validated staged
workflow. `qe/` contains PWscf and `pp.x` inputs generated during the shortened
notebook benchmark.

These files are references, not universal templates. Before rerunning:

- update pseudopotential paths;
- update Slurm account and resources;
- preserve the pseudopotential filenames;
- confirm k-points, cutoffs, spin treatment, cell dimensions, and convergence
  criteria for the target system.

QE inputs reflect the last calculation written in each notebook directory.
Convergence-loop directories therefore contain the final loop member rather
than every overwritten intermediate input.
